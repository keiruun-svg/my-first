# 수익성 분석 엔진 (`lib/profitabilityEngine.ts`)

수입(FLC) vs 국내생산(맥산) 생산방식 권고 로직.  
UI 의존성 없음 — 어느 탭에서든 import 가능.

---

## 개요

품목별로 맥산 생산원가 / FLC 수입원가 / 판매가를 비교해 5가지 권고 중 하나를 반환한다.  
**판매가가 절대 기준**이며, 원가가 아무리 저렴해도 판매가를 초과하면 철수검토로 처리된다.

---

## 입력 데이터

| 항목 | 설명 |
|------|------|
| 맥산 생산원가 파일 | `맥산원가` 컬럼 → 생산원가로 적용 |
| FLC 수입원가 파일 | `생산원가`, `표준원가` 컬럼 |
| 계약 단가 파일 (선택) | `품목코드`, `단가` 컬럼 |
| 판매 이력 | `DetailedSalesRow[]` — 계약 단가가 없는 품목의 평균 판가 계산에 사용 |

### 원가 적용 규칙

```
classifyOjc(품목명) → 'KT OJC' 로 시작 → 표준원가
                    → 그 외 (LG향·기타)  → 생산원가
```

### 판매가 결정 (우선순위)

1. 계약 단가 파일에 해당 품목코드가 있고 단가 > 0 → 계약 단가
2. 없으면 → 판매 이력 `totalPrice / totalQty` (연도 무관 전체 평균)

---

## 설정값 3가지

### ① 최소 마진율 `minMarginPct` (기본 0%)

이 값 미만인 마진은 원가 구조 자체가 부적절한 것으로 판단 → 무조건 **철수검토**.  
영업 부서의 마진 하한선을 입력해야 의미 있는 결과를 얻을 수 있다.

### ② 생산유지기준 (자동 파생, 직접 설정 불가)

```
생산유지기준 = max(20, minMarginPct × 3)
```

- 최소마진 5% → max(20, 15) = **20%**
- 최소마진 10% → max(20, 30) = **30%**
- 검토필요 구간: minMarginPct ≤ 마진율 < 생산유지기준

### ③ 맥산 생산 가중치 `thresholdEnabled` / `bufferPct` (기본 OFF)

```
importThreshold = thresholdEnabled ? 100 + bufferPct : 100
```

- **OFF**: FLC가 1원이라도 저렴하면 수입 권고 가능
- **ON (bufferPct=10%)**: 맥산이 FLC 대비 10%까지 비싸도 생산 유지로 처리

국내 생산의 납기 안정성·품질 이점을 비용으로 환산한 버퍼 개념.

---

## 마진율 계산

```
마진율 = (판매가 − 원가) / 판매가 × 100
```

판매가 = 0 이거나 없으면 마진율 = null.

---

## 권고 결정 로직 `getReco(row, threshold, minMarginPct)`

### 전제 조건

판매가 없거나 ≤ 0 → **판매가 없음** (권고 불가)

### 분기 A: 맥산·FLC 원가 양쪽 모두 있을 때

| 조건 | 권고 |
|------|------|
| 맥산마진 < 최소 AND FLC마진 < 최소 | ⚠ 철수검토 |
| 맥산마진 < 최소 AND FLC마진 ≥ 최소 | 📦 수입 권고 |
| 양쪽 마진 ≥ 최소 AND 맥산원가 > FLC원가 × threshold | 📦 수입 권고 |
| 맥산마진 ≥ 생산유지기준 AND 맥산원가 > FLC원가 (가중치로 이긴 케이스) | ⚖ 맥산 생산 가능 |
| 맥산마진 ≥ 생산유지기준 (맥산이 원래 더 저렴) | ✅ 맥산 생산 권고 |
| 최소 ≤ 맥산마진 < 생산유지기준 | 🔍 검토필요 |

> `!맥산미달 AND FLC미달` 케이스(FLC만 나쁨): threshold 조건 생략 → 맥산 마진율만으로 생산유지/검토필요 결정

### 분기 B: 맥산 원가만 있을 때

| 조건 | 권고 |
|------|------|
| 마진 < 최소 (또는 null) | ⚠ 철수검토 |
| 마진 ≥ 생산유지기준 | ✅ 맥산 생산 권고 |
| 그 외 | 🔍 검토필요 |

### 분기 C: FLC 원가만 있을 때

| 조건 | 권고 |
|------|------|
| 마진 < 최소 (또는 null) | ⚠ 철수검토 |
| 마진 ≥ 생산유지기준 | 📦 수입 권고 |
| 그 외 | 🔍 검토필요 |

## 신호등 `marginSignal(v)`

권고와 독립적으로 마진율 수준을 표시.

| 값 | 신호 | 의미 |
|----|------|------|
| ≥ 20% | 🟢 | 수익성 양호 |
| 0 ~ 20% | 🟡 | 수익성 낮음, 영업 확인 필요 |
| < 0% | 🔴 | 원가 > 판매가 |

### 신호등 기준 마진율 `getSignalMargin(row, label)`

- 수입 권고 → FLC 마진율
- 맥산 생산 권고/가능, 검토필요 → 맥산 마진율
- 철수검토 → 양쪽 중 더 나은 값 (얼마나 심각한지 표시)

## 수치 예시

**설정**: 판매가=100, 최소마진=5%, 가중치=ON bufferPct=10%  
→ threshold=110%, 생산유지기준=max(20, 15)=**20%**

| 맥산원가 | FLC원가 | 맥산마진 | FLC마진 | 권고 | 신호 |
|---------|---------|---------|---------|------|------|
| 110 | 80 | -10% | 20% | 📦 수입 권고 | 🟡 (FLC 20%) |
| 110 | 110 | -10% | -10% | ⚠ 철수검토 | 🔴 |
| 93 | 84 | 7% | 16% | 📦 수입 권고 (93>92.4) | 🟡 (FLC 16%) |
| 90 | 84 | 10% | 16% | 🔍 검토필요 | 🟡 (맥산 10%) |
| 75 | 84 | 25% | 16% | ✅ 맥산 생산 권고 | 🟢 (맥산 25%) |
| 88 | 84 | 12% | 16% | ⚖ 맥산 생산 가능 (88>84, 88<92.4) | 🟡 (맥산 12%) |

## 다른 곳에서 재사용하는 법

```typescript
import { getReco, getSignalMargin, marginSignal } from '../lib/profitabilityEngine'
import type { ProfitRow } from '../lib/profitabilityEngine'

const reco = getReco(row, importThreshold, minMarginPct)
const sig  = marginSignal(getSignalMargin(row, reco.label))
// reco.label → '✅ 맥산 생산 권고' | '⚖ 맥산 생산 가능' | '📦 수입 권고' | '🔍 검토필요' | '⚠ 철수검토'
// reco.bg, reco.text → Tailwind 클래스 (뱃지 스타일링용)
// sig → '🟢' | '🟡' | '🔴' | ''
```
