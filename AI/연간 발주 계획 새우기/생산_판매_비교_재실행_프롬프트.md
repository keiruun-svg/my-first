## 핵심 계산 규칙

```python
# 수입추정
수입추정(월) = MAX(0, 판매 - 생산)   # 일반 품목
수입추정(월) = None                   # DROP-CABLE (케이블종류 == 'drop')

# 생산비중
생산비중 = 연간생산 / 연간판매        # 판매=0이면 None
```

### DROP-CABLE 처리
- 케이블종류 컬럼 값이 `'drop'`인 경우 → 전량 자체 생산
- 수입추정 강제 None, 비고: '전량생산(DROP-CABLE)'

### 데이터 소스 컬럼 위치

**가공파일_통합_v양식.xlsx** (케이블 시트: `23년_케이블`, `24년_케이블`, `25년_케이블`)
| 열 | 내용 |
|----|------|
| A(0) | 품목코드 |
| B(1) | 품목명 |
| C(2) | 규격명 |
| D(3) | 케이블 종류 (drop 여부 판별) |
| J~U (9~20) | 1~12월 생산수량 |

**판매량_정리.xlsx** (시트: `23년_완제품`, `24년_완제품`, `25년_완제품`)
| 열 | 내용 |

| C(2) | 품목명 |
| D(3) | 규격명 |
| E~P (4~15) | 1~12월 판매수량 |
