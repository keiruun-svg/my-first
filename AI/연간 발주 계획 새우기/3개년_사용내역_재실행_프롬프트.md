## 계산 규칙

### 케이블
```
월별 소모량(m) = OJC 월별 생산수량 × 케이블 길이(m)
파이 정규화: '0.9' → '0.9mm'
0.9mm 피그테일: 참고파일 직접 사용

케이블종류 매핑:
  a1 + core=1 → A1-SP / a1 + core=2 → A1-DP
  b3 + core=1 → B3-SP / b3 + core=2 → B3-DP
  a1-청/녹/적/자 → A1_청-SP/DP 등
  drop → DROP / pigtail (0.9mm 제외) → PIGTAIL
```

### 하우징 (타입1/2 역추적)
```python
MM_KINDS = {'om1', 'om1-pigtail', 'om3'}
# SIDE A(타입1) → 주색 += 월별수량 × 코어수
# SIDE B DP+일반 → 적색 += 월별수량 × 코어수
# SIDE B SP·다심 → 주색 += 월별수량 × 코어수
# LC/PC + MM + 2.0mm → BEIGE
def is_multicore(k): return bool(re.match(r'^(b3|a1)-\d+c$', k))
```
