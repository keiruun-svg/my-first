========================================================
  AJW OJC 연간 발주 계획 — 독립 실행 안내
========================================================

[ 사전 준비 ]
  Python 3.8 이상 설치 필요 (https://www.python.org)
  필요 라이브러리: pip install openpyxl

[ 파일 구성 ]
  STEP1_사용내역_생성.py     ← 사용내역 자동 생성
  STEP2_발주계획_생성.py     ← 발주계획 자동 생성
  전체실행.bat               ← Windows 더블클릭 실행
  가공파일_통합_v양식.xlsx   ← ROW 데이터 (필수)

[ 실행 순서 ]

  STEP 1. 사용내역 생성
  ─────────────────────
  - STEP1_사용내역_생성.py 더블클릭 (또는 python STEP1_사용내역_생성.py)
  - 생성된 3개년_생산자재_사용내역.xlsx 열기
  - 현재고, 기발주 입력 (빨간 ⚠ 항목은 품번도 입력)
  - 파일 저장 후 닫기

  STEP 2. 발주계획 생성
  ─────────────────────
  - STEP2_발주계획_생성.py 더블클릭 (또는 python STEP2_발주계획_생성.py)
  - 생성된 2026_연간발주계획.xlsx 열기
  - 노란색 셀에 2026 목표 발주량 입력
  - 필요 발주량이 자동 계산됩니다

[ 갱신 주기 ]
  - ROW 데이터 업데이트 시: STEP 1 → STEP 2 순서로 재실행
  - 현재고만 업데이트 시: 사용내역 파일 직접 수정 → STEP 2 재실행
  - 분기 단위로 현재고 업데이트 권장
