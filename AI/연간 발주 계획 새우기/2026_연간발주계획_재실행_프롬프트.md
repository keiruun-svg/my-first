# ══ STEP 1: 3개년_생산자재_사용내역.xlsx 생성 ═════════════

## 필요 파일
- `가공파일_통합_v양식.xlsx` (ROW 데이터)

## 작업 내용
ROW 데이터에서 케이블·하우징 3개년 실사용량을 계산하여 아래 구조의 파일 생성

### 케이블 사용내역 시트
| 컬럼 | 내용 | 계산 방법 |
|------|------|-----------|
| 파이 | 2.0mm / 3.0mm / 0.9mm | ROW 데이터 파이 컬럼 |
| 케이블 종류 | A1-SP, A1-DP, B3-SP 등 | ROW 데이터 케이블종류 + 코어수 |
| 23/24/25년 연간(m) | 연도별 연간 총 소모량 | 월별수량 × 케이블길이(m) 합계 |
| 23/24/25년 피크(m) | 연도별 최대 월 소모량 | 12개월 중 최대값 |
| 3개년 평균·피크 평균 | 수식 자동 계산 | AVERAGE |
| **품번·품명·구매처·리드타임·현재고** | **기존 참고파일 자동 매칭** | 매칭 안되면 빈칸(⚠ 표시) |

### 하우징 사용내역 시트
- 타입1/2 역추적 방식으로 월별 정확 계산
- SC/PC·SC/APC: SPRING·HOUSING·DUST CAP·STOPPER·FRAME·BOOT 6개 컴포넌트 각 행
- 구매용도 컬럼으로 각 부품 역할 표시

### 케이블 집계 규칙
```python
# 월별 소모량(m) = OJC 월별 생산수량 × 케이블 길이(m)
# 파이 정규화: '0.9' → '0.9mm'
# 0.9mm 피그테일은 기존 참고파일 직접 사용
# 케이블종류 매핑: a1+core1→A1-SP, a1+core2→A1-DP, b3+core1→B3-SP 등

MM_KINDS = {'om1', 'om1-pigtail', 'om3'}
```

### 하우징 집계 규칙
```python
# SIDE A(타입1) → 주색 += 월별수량 × 코어수
# SIDE B DP+일반케이블 → 적색 += 월별수량 × 코어수
# SIDE B SP·다심 → 주색 += 월별수량 × 코어수
# LC/PC + MM + 2.0mm → BEIGE
def is_multicore(kind): return bool(re.match(r'^(b3|a1)-\d+c$', kind))
```

### ⚠ 생성 후 수동 입력 필요 항목
- 품번 매칭 안된 케이블 (⚠ 표시된 행): 품번·구매처·리드타임 직접 입력
- 현재고·기발주: 분기마다 업데이트 필요

## 필요 파일
| 파일 | 역할 |
|------|------|
| `가공파일_통합_v양식.xlsx` | ROW 데이터 (생산수량) |
| `3개년_생산자재_사용내역.xlsx` | 품번·구매처·리드타임·현재고 메타데이터 |

## 시트 구성 (4개)

### 케이블 사용내역
컬럼: NO | 파이 | 케이블종류 | 품번 | 품명 | 구매처 | 리드타임(일) | 23년연간(m) | 23년피크(m) | 24년연간 | 24년피크 | 25년연간 | 25년피크 | 3개년평균 | 3개년피크평균 | 23→24증감률 | 24→25증감률 | **안전재고** | 현재고 | 기발주 | **2026목표(입력)** | 필요발주량 | 비고

안전재고 = 3개년피크평균 × (리드타임 ÷ 30)

### 하우징 사용내역
동일 구조, SC/PC 등 6개 컴포넌트 각 행, 목표 입력은 첫 행만 → 나머지 자동 연동

### 2026 월별 발주계획
연간목표 입력 → 과거 3개년 계절 패턴으로 1~12월 자동 분배

### ⚠ 이상항목 검토
자동 감지: OM4 미사용, OM3 감소, 피그테일 급감
