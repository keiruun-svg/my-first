## 4. 3개년_생산자재_사용내역.xlsx

### 자동 계산
- 케이블: 월별수량 × 길이(m), 연간/피크, 3개년 평균
- 하우징: 타입1/2 역추적, 연간/피크

### 담당자 직접 입력
| 항목 | 빈도 |
|------|------|
| 현재고 | 분기마다 |
| 기발주 | 발주할 때마다 |
| ⚠ 품번·구매처·리드타임 | 신규 자재 발생 시 |

### 현재 ⚠ 항목 (직접 입력 필요)
- (2.0mm, B3-4C): 신규 자재
- (2.0mm, OM3-SP): 소량 사용
- (2.0mm, PIGTAIL): 2.0mm 자켓 피그테일 품번 확인

### ROW 데이터 분류 이슈 (스크립트에서 자동 보완)
- **(2.0mm, A1-4C)**: 4코어 OJC 제품이 ROW에서 b3-4c로 분류 → A1-4C 누락 → **참고파일에서 자동 보완** (24년=235m, 25년=2,000m)
- **(2.0mm, OM4-DP)**: ROW 집계 안됨 (소량) → **참고파일에서 자동 보완** (23년=511m)
- 보완 조건: 같은 폴더에 `비밀_OJC 3개년 생산자재 사용 내역_*.xlsx` 있을 때 자동 적용

### STEP1 버그 수정 이력 (2026-04-28)
- **버그**: `if not pai: continue; p=np(pai)` → `;` 뒤 `p=np(pai)`가 if 블록 안에 있어 실행 안됨
- **증상**: 하우징이 2.0mm 13타입만 집계됨 (3.0mm 12타입, 0.9mm 5타입 누락)
- **수정**: 두 줄로 분리 → `if not pai: continue` / `p_h = np(pai)` → 30타입 정상 집계
