> 이 문서를 새 대화 시작 시 붙여넣고, 구매조회 xlsx 파일을 첨부한 뒤  
> **"이 파일 변환해줘"** 라고 입력하면 동일한 결과물을 얻을 수 있습니다.

## 역할 및 작업 개요

당신은 (주)에이제이월드의 OJC(광점퍼코드) 구매 데이터를 분석하는 전문가입니다.  
첨부된 구매조회 xlsx 파일을 읽어 **2개 시트로 구성된 가공파일**을 생성하세요.

## 3. OJC 제품 지식

### 커넥터 종류 (3종)
SC, LC, FC

### 페롤 타입 (2종)
| 페롤 | 하우징 색상 |
|------|------------|
| PC (Physical Contact) | SM→청색, OM1·OM3 LC→베이지 |
| APC (Angled Physical Contact) | 녹색 |

→ 타입 조합 6종: `LC/PC`, `LC/APC`, `SC/PC`, `SC/APC`, `FC/PC`, `FC/APC`

### 품명 규칙

**LG향 (SOJC/DOJC/MOJC)**
```
SOJC-{SM/MM}-{ConnA/FerrA}-{ConnB/FerrB}-{길이}M   ← Simplex (1심)
DOJC-{SM/MM}-{ConnA/FerrA}-{ConnB/FerrB}-{길이}M   ← Duplex (2심)
MOJC-{SM/MM}-{N}C-{ConnA/FerrA}-{ConnB/FerrB}-{길이}M  ← 다심
```

**KT향 (OJC-A1/A2/C2)**
```
OJC-{재질}-{ConnA/ConnB}-{SM/MM}-{길이}-{FerrA/FerrB}-{SP/DP/NC}
```
- 커넥터(pos 3)와 페롤(pos 6)이 분리 저장
- 타입1 = ConnA+"/"+FerrA, 타입2 = ConnB+"/"+FerrB

**DROP 케이블**
```
DROP-CABLE({Conn/Ferr})              ← 양끝 동일, 1심
DROP-CABLE({ConnA/FerrA}-{ConnB/FerrB})  ← 양끝 다름
DROP-CABLE({Conn/Ferr})-2C           ← 2심
```

**PIGTAIL**
```
PIGTAIL-{Conn/Ferr}-{SM/MM}-{N}C({파이})
```
- 한쪽 끝에만 커넥터 → 타입1만, 타입2 없음

## 4. 타입1/타입2 추출 함수

```python
import re
CONN = r'(?:SC|LC|FC)'; FERR = r'(?:PC|APC)'; TYPE_PAT = f'({CONN}/{FERR})'

def extract_types(p):
    p = str(p).strip()
    if p.startswith('DROP'):
        m = re.search(r'\((.+?)\)', p)
        if m:
            t = re.findall(TYPE_PAT, m.group(1))
            if len(t)>=2: return t[0],t[1]
            if len(t)==1: return t[0],t[0]
        return '',''
    if p.startswith('PIGTAIL'):
        t = re.findall(TYPE_PAT, p); return (t[0],'') if t else ('','')
    if p.startswith('OJC-'):
        parts = p.split('-')
        conn = next((x for x in parts if re.match(r'^(SC|LC|FC)/(SC|LC|FC)$',x)),None)
        ferr = next((x for x in parts if re.match(r'^(PC|APC)/(PC|APC)$',x)),None)
        if conn and ferr:
            cA,cB=conn.split('/'); fA,fB=ferr.split('/')
            return f'{cA}/{fA}',f'{cB}/{fB}'
        return '',''
    if p.startswith(('SOJC','DOJC','MOJC')):
        t = re.findall(TYPE_PAT, p)
        if len(t)>=2: return t[0],t[1]
        if len(t)==1: return t[0],t[0]
        return '',''
    if p.startswith('Optical Cable Parts'):
        t = re.findall(TYPE_PAT, p)
        if len(t)>=2: return t[0],t[1]
        if len(t)==1: return t[0],t[0]
        return '',''
    return '',''
```

## 5. 케이블 속성 도출 규칙

### 케이블 종류 (`derive_kind`) — 위에서 아래로 순서대로 적용 (먼저 매칭된 규칙 우선)

| 순위 | 조건 | 종류 |
|------|------|------|
| 1 | PIGTAIL + (MM 또는 OM3 포함) | `om1-pigtail` |
| 2 | PIGTAIL | `pigtail` |
| 3 | DROP | `drop` |
| 4 | Optical Cable Parts | `a2` |
| 5 | MOJC + `-{N}C-` 패턴 | `b3-{N}c` (예: b3-6c, b3-12c) |
| 6 | OJC-C2 + 4코어 | `b3-4c` |
| 7 | OJC-C2 + 4코어 외 | `a1-{N}c` (예: a1-8c, a1-12c) |
| 8 | 규격명에 `B3` 포함 | `b3` |
| 9 | MM(OM3) 또는 OM3 포함 | `om3` |
| 10 | `-MM-` 또는 `-MM` 포함 | `om1` |
| 11 | 규격명에 청/적/녹/자 포함 | `a1-청` / `a1-적` / `a1-녹` / `a1-자` |
| 12 | 나머지 | `a1` |

### 파이 (`derive_pai`)
| 조건 | 파이 |
|------|------|
| PIGTAIL + 0.9mm 표기 | `0.9` |
| PIGTAIL + 2.0mm/MM/OM3 | `2.0mm` |
| PIGTAIL 나머지 | `0.9` |
| DROP | `3.0mm` |
| MM/OM3/MOJC/OJC-A1 | `2.0mm` |
| SOJC/DOJC + 규격에 3.0mm | `3.0mm` |
| 규격에 3.0mm | `3.0mm` |
| 나머지 | `2.0mm` |

### 코어수 (`derive_core`)
- `MOJC-SM-NC-` 패턴 → N
- `PIGTAIL-...-NC` 패턴 → N
- `OJC-C2-...-NC` 패턴 → N
- **`Optical Cable Parts,...,NCCore` → 품목명에서 직접 파싱** (하드코딩 금지)
- DROP + 2C → 2, DROP 나머지 → 1
- DOJC → 2, SOJC → 1
- `-SP` → 1, `-DP` → 2
- 나머지 `-NC` → N
- 나머지 → 1

## 6. 하우징 수량 계산 규칙 ★핵심★

### 기본 원칙 (개별 커넥터 기준)
```
cps = 코어수   ← 모든 케이블 동일, 예외 없음
```

- **SIDE A (타입1)** → 주색 컬럼 × cps × qty
- **SIDE B (타입2)** → SP(코어<2)이면 주색, DP(코어≥2)이면 적색 × cps × qty
- **단, MOJC/OJC-C2 (케이블종류 b3-Nc / a1-Nc)는 SIDE B도 주색 사용 (적색 없음)**

### 색상 결정 규칙
| 커넥터/페롤 | 케이블 종류 | SIDE A 컬럼 |
|------------|------------|------------|
| LC/PC | om1, om1-pigtail, om3 (OM1·OM3) | **베이지(BEIGE)** |
| LC/PC | SM (om1·om3 제외) | 청색 |
| LC/APC | - | 녹색 |
| SC/PC | - | 청색 |
| SC/APC | - | 녹색 |
| FC/PC | - | 흑색 |
| FC/APC | - | 녹색 |
| 모든 타입 | SIDE B + DP | **적색** |

> ★ OM3(om3)는 OM1과 동일하게 BEIGE 적용  
> ★ MM_KINDS = `{'om1', 'om1-pigtail', 'om3'}` 모두 BEIGE 적용

### 검증 예시
| 품목 | qty | cps | 기대 계산수량 |
|------|-----|-----|------------|
| DOJC-SM-LC/PC-LC/PC | 10 | 2 | 청색20 + 적색20 = **40** |
| DOJC-MM-LC/PC-LC/PC (OM1) | 11 | 2 | BEIGE22 + 적색22 = **44** |
| DOJC-MM(OM3)-LC/PC-LC/PC | 7 | 2 | BEIGE14 + 적색14 = **28** |
| OJC-C2-4C-SC/PC, 20개 | 20 | 4 | 청색80 + 청색80 = **160** |
| MOJC-12C-SC/PC, 24개 | 24 | 12 | 청색288 + 청색288 = **576** |
| DROP-2C-LC/PC, 20개 | 20 | 2 | 청색40 + 적색40 = **80** |
| Optical Parts 2Core-LC/PC, 40개 | 40 | 2 | 청색80 + 적색80 = **160** |
| PIGTAIL-LC/PC-SM-1C(0.9) | 5 | 1 | 청색5 (SIDE B 없음) = **5** |

## 5-1. 케이블 길이 추출 규칙 (`derive_length`)

품목명(col 6)에서 숫자+M 패턴으로 추출. 단위는 M(미터), 정수 또는 소수.

| 품목 패턴 | 파싱 방법 | 예시 |
|---|---|---|
| SOJC / DOJC / MOJC | 품목명 끝의 `-{N}M` | `DOJC-SM-LC/PC-LC/PC-10M` → 10 |
| OJC-A1 / A2 / C2 | 품목명 중 `-{N}M-` 또는 `-{N}M` | `OJC-A1-LC/SC-SM-10M-PC/PC-SP` → 10 |
| DROP-CABLE | 품목명 중 숫자+M | `DROP-CABLE(LC/PC)-10M` → 10 |
| PIGTAIL | 규격명 또는 품목명 중 숫자+M | `PIGTAIL-LC/PC-SM-1C(0.9)-1.5M` → 1.5 |
| Optical Cable Parts | 규격명 중 숫자+M | 규격명에서 파싱 |
| 파싱 실패 | 빈값(`""`) 처리, 경고 출력 | |
